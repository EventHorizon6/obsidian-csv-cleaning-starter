    What the scanner checks

    • Structure: delimiter, encoding, rows with the wrong number of cells, unclosed quotation marks, blank or repeated column names, blank rows.
    • Records: exact duplicate rows; rows that share an ID, email or code column but disagree (conflicts) or only fill each other's gaps.
    • Values: missing values, placeholders such as N/A or null, dates that cannot be read or mix day-first and month-first order, numbers that cannot be read, and numeric columns with inconsistent formats.
    • Safety: cells that a spreadsheet would run as a formula (CSV injection).
    • Import risks: leading zeros that spreadsheets drop, long numbers that spreadsheets round, line breaks inside cells, cells too long for a spreadsheet, and extra spaces.

    Not supported

    • Excel workbooks (.xlsx, .xls), OpenDocument, Numbers, JSON or PDF files: export the sheet as CSV first.
    • Files over 25 MB, 100,000 rows or 1,000,000 cells, and single cells over 2 million characters.
    • Fuzzy matching (similar names or addresses), checks against a particular platform's import template, and validating emails, phone numbers or addresses against the real world.
    • Dates are judged by their shape: a column whose dates could all be read either way (for example 03/04/2025) is not flagged.
